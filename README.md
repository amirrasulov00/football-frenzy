# Football Frenzy

## Beskrivning
Programmet hämtar fotbollsresultat från Football Frenzy API och visar alla matcher från ett valt år som slutade med ett angivet resultat.

## Funktioner
- Användaren anger årtal.
- Användaren anger hemmalagets och bortalagets antal mål.
- Programmet hämtar matchdata via HTTP API-anrop.
- Programmet filtrerar matcher efter exakt resultat.
- Matcherna skrivs ut med datum, lagnamn och resultat.

## Teknik
- Python
- HTTP och REST API
- JSON
- Tredjepartsbiblioteket `pyodide.http.pyxhr`
- Loopar, villkor och stränghantering
